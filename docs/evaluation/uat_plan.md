# Milestone 13 User Acceptance Testing Plan

## Status

**NOT YET EVALUATED.** No real participants were available during this milestone. No feedback, completion times, satisfaction scores, or pharmacy outcomes have been fabricated.

## Recommended participants

- Pharmacy staff member or pharmacy worker
- Administrator or pharmacy manager
- Technically knowledgeable evaluator

Use synthetic medicines, rules, and patient context only. Do not enter real patient-identifying data.

## Facilitated task script

1. Log in and identify the current role.
2. Find a named medicine using search and filters.
3. As an administrator, add a synthetic batch.
4. Perform a Direct Sale and locate the completed transaction.
5. Process a synthetic External Prescription.
6. Process a synthetic Consultation.
7. Review a controlled synthetic clinical warning.
8. Explain the warning and acknowledge it before confirmation.
9. Find transaction history and verify its detail record.
10. As an administrator, review governance summary, rule history, and an export.

For each task record success, elapsed time, user errors, requests for assistance, comments, and any observed defect ID. Stop a scenario if data integrity or clinical-safety behavior appears compromised.

## Questionnaire

Rate each statement from **1 = Strongly Disagree** to **5 = Strongly Agree**.

1. The system is easy to navigate.
2. Medicine information is easy to find.
3. Inventory information is clear.
4. Dispensing workflows are understandable.
5. Clinical warnings are easy to understand.
6. Explanations are useful and traceable.
7. The system provides enough information before confirmation.
8. The interface is consistent.
9. I could use the system with minimal assistance.
10. Overall, the system is useful for community pharmacy operations.

Open-ended questions:

- What did you find easiest?
- What was difficult?
- Which feature was most useful?
- Which feature needs improvement?
- Did any warning or message confuse you?
- What would you change?

## Analysis approach

Report task success as counts and percentages, task time using median and range, errors and assistance requests as observed counts, and Likert responses using item medians and distributions. Preserve anonymous raw responses. Do not generalize beyond the recruited sample.
